# SkySense-V1

This is a compact, lightweight drone expansion PCB designed to add useful monitoring features to compatible DIY drones. Powered by an ESP32-C3, it combines sensors 
to measure altitude, temperature, battery voltage, and motion, while transmitting data to a flight controller. The goal is to create an affordable, customizable, and 
open-source module that makes DIY drones smarter and more informative.
